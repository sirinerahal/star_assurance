STAR Assurances — PROJECT CONTEXT

1. Objectif du projet

Plateforme IA de recommandation de produits d’assurance pour STAR Assurances.

L’application analyse le profil client, les contrats existants et les informations disponibles afin de proposer les produits les plus pertinents, avec une explication personnalisée.

Le projet existe déjà. Il ne faut PAS le recréer depuis zéro. Toutes les fonctionnalités fonctionnelles doivent être conservées.

2. Architecture

Frontend

React / Next.js / TypeScript

Communication avec le Backend via API REST

Fichier important : lib/api.ts

Variable d’API : NEXT_PUBLIC_API_URL

Valeur locale par défaut : http://127.0.0.1:8000

Backend

Python / FastAPI

API REST

Chargement des données et du modèle ML au démarrage

Gestion notamment des clients, recommandations, campagnes et chatbot

4. Système de recommandation

Flux général :
Client → Profil → Modèle ML → Scores → Produits pertinents → Recommandations → Explication personnalisée.

Endpoint principal :
GET /recommandations/{client_id}

Paramètre :
avec_explication

Le Frontend appelle cet endpoint via lib/api.ts.

Vérifier :

chargement du modèle ;

données utilisées pour la prédiction ;

calcul des scores ;

sélection des produits ;

cohérence avec le profil client ;

prise en compte des produits déjà détenus selon la logique existante ;

explication personnalisée ;

intégration Backend → Frontend ;

affichage ;

cas sans recommandation ;

erreurs et cas limites.

Ne pas remplacer le modèle ML existant sans raison technique claire et validation préalable.

5. IA générative / Groq

Groq est utilisé notamment pour :

explication des recommandations ;

chatbot ;

génération de contenu Email/SMS.

La clé Groq est sensible :

ne jamais l’exposer dans le Frontend ;

ne jamais la hardcoder ;

la conserver côté Backend/environnement ;

ne jamais l’afficher dans les erreurs ou logs.
